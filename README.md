🌷 DAILYBOARD

DailyBoard adalah website dashboard produktivitas harian yang dibuat untuk membantu mengatur berbagai kegiatan dalam satu tempat ✨

Di dalam DailyBoard terdapat beberapa fitur seperti to-do list 📝, notes 📒, kutipan dan widget cuaca 🌤️. Website ini dibuat menggunakan HTML, CSS, dan JavaScript.

🎓 DailyBoard merupakan tugas akhir semester dari proyek JavaScript selama satu semester.

✨ Fitur DailyBoard

📝 To-Do List

Digunakan untuk mencatat tugas atau kegiatan yang ingin dilakukan.

Pengguna dapat:

- ➕ Menambahkan tugas baru
- ✅ Menandai tugas yang sudah selesai
- 🗑️ Menghapus tugas
- 📋 Melihat daftar tugas yang sudah selesai & belum selesai
- Drap & Drop urutan tugas
- Mengedit Tugas

📒 Notes

Tempat untuk menulis catatan singkat atau hal-hal penting yang ingin disimpan.

Pengguna dapat :
- Menambah catatam
- Mengedit Catatan
- Menghapus Catatan
- Data tersimpan

🌤️ Weather Widget

Widget cuaca yang digunakan untuk melihat informasi cuaca secara langsung pada dashboard.

- Mencari nama daerah untuk mengetahui cuaca
- Menampilkan suhu dan kondisi cuaca nama daerah yang sudah dicari 

💾 Local Storage

Data yang dibuat pada DailyBoard dapat disimpan menggunakan Local Storage, sehingga data tetap tersimpan di browser dan tidak langsung hilang ketika halaman di-refresh.

KUTIPAN HARIAN
Memunculkan beberapa kutipan random.

MENGUBAH TEMA GELAP & TERANG

📖 Cara Menggunakan

1. 🌐 Buka DailyBoard

Buka website melalui:

https://vaniaahass.github.io/DAILYBOARD/

2. 📝 Tambahkan To-Do

Masukkan tugas atau kegiatan yang ingin dilakukan ke bagian To-Do List, kemudian tambahkan ke daftar.

Jika tugas sudah selesai, tandai tugas tersebut sebagai selesai ✅

3. 📒 Buat Catatan

Gunakan bagian Quick Notes untuk menulis catatan singkat yang ingin disimpan.

4. 🌤️ Cek Cuaca

Lihat bagian Weather Widget untuk mengetahui informasi cuaca yang tersedia pada dashboard.
